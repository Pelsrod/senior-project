This is a character or turn organizer I made while I attended Manchester University.
This website ended up becoming my senior project, but I still plan to update here and there.
Essentially, this is meant to be a paper-pencil aid for the ttrpg.
It should be understood that the character is created beforehand, with the website being used to filter or store information that might not fit into the dnd character sheet.
I've decided to make the website function mostly on user input because I like running homebrew items and classes. Just ask my fiancé lol.
Once a character is created, they can either be saved locally and/or by external download. The downloaded file will be a JSON file with your character's name as the file name.
That's kinda it. I planned to add more after I graduated, but haven't gotten around to it. I do, however, still plan on continuing this project.
